# kepos
A private garden for 30 friends. Write treeholes that can never be deleted, draw and guess, chat — with no servers.

## P2P chat prototype

This first draft is a terminal chat room built on Hyperswarm. It has no server,
no account system, and no message history. A room is just a shared 32-byte key.

Install dependencies:

```bash
npm install
```

Create a room:

```bash
npm start -- create --nick Neil
```

Share the printed room key with another peer, then join from another terminal or
machine:

```bash
npm start -- join <room-key> --nick Ada
```

Current scope:

- create a room key
- join a room by key
- discover peers through Hyperswarm
- send live text messages to connected peers

Not in this draft:

- Hypercore message history
- member invitations or bans
- treehole comments or likes in the UI
- games
- mobile UI

## Android prototype

The mobile draft is an Expo React Native app with a Bare worklet backend. The UI
runs in React Native. Hyperswarm runs in Bare through `react-native-bare-kit`,
and the two sides talk through `bare-rpc`.

Build the Bare backend bundle:

```bash
npm run backend:bundle:android
```

Build/run a native Android dev app:

```bash
npm run android
```

Build a debug APK without installing it:

```bash
npm run android:assemble
```

Current Android scope:

- create room UI
- join room UI
- room header and peer status
- message list and composer
- room tabs for live chat and treehole feed
- shared chat session state with tests
- Bare worklet backend
- React Native to Bare RPC
- Hyperswarm room join/send/receive in the backend
- Autobase-backed treehole event log
- pure text treehole posts
- writer-key exchange for multiwriter treehole replication

Treehole data model:

- `treehole.post.create`
- `treehole.comment.create`
- `treehole.like.add`

Only text posting is exposed in the Android UI right now. Comments and likes are
covered in the event reducer so the data model can grow without replacing the
Autobase log.

Notes:

- This needs a native development build. Expo Go cannot load `react-native-bare-kit`.
- Android min SDK is 29 because `react-native-bare-kit` requires it.
- `android/` is generated by Expo prebuild and is not committed.
