Kepos / current prototype

私人花园里的 P2P 房间。

Kepos 现在已经有多人房间、实时文字聊天和纯文本树洞原型。核心方向是不依赖业务服务器，让移动端、桌面端和命令行端都能作为 peer 参与测试。

当前能力

3 可测试端
P2P Hyperswarm 房间
Text 聊天与树洞

这是产品原型说明页，不是发布页。它描述的是当前仓库已经实现并可本地验证的功能。

已有功能

第一版聚焦多人房间和文字内容。图片、账号体系、审核后台、正式邀请流还没有进入当前实现。

room

创建和加入房间

可以生成 32-byte room key，其他 peer 用同一个 key 加入。房间 topic 从 key 派生，用 Hyperswarm 做发现和连接。

chat

实时文字聊天

房间内支持 live text message。消息在当前会话中展示，并做了基本的重复消息过滤。

treehole

纯文本树洞

树洞采用 Autobase 事件日志。当前 UI 暴露发纯文本帖子；数据模型已经包含评论和点赞事件。

multiwriter

树洞 writer 交换

peer 会交换 treehole bootstrap key 和 writer key，让多端可以加入同一个 Autobase treehole 日志并复制内容。

native

Android Bare 后端

Android UI 运行在 React Native，P2P 后端运行在 Bare worklet，两边通过 bare-rpc 通信。

tooling

代码风格和边界检查

项目已有 prettier、lunte、lefthook，并检查桌面依赖不泄漏到 Android 构建。

支持的端

当前目标是能做 two-device path：手机和桌面端互相作为 peer 测试。

Android

原生开发构建可测

Expo React Native + react-native-bare-kit。支持创建/加入房间、聊天、树洞 tab、Bare P2P 后端和 Autobase treehole。

Desktop

Electron + pear-runtime

桌面端已经从旧 pear run 切到官方最新方向：Electron 主进程内嵌 pear-runtime，用于和 Android 做 peer 测试。

CLI

终端房间原型

命令行端可以创建/加入房间并发送实时文字消息，适合快速验证协议和 P2P 连接。

iOS

暂未接入

当前没有 iOS 构建路径。后续如果做移动双端，需要单独验证 Bare/iOS 集成和 native module 链接。

Web

暂不支持

当前 P2P 栈依赖 native/Bare 能力，浏览器 Web 端不是第一阶段目标。

Server

没有业务服务器

Kepos 当前不是 client-server 产品；已有后端是 Android 内部 Bare worklet，不是中心化服务。

运行入口

  • npm start -- create --nick Neil
  • npm start -- join <room-key> --nick Ada
  • npm run android
  • npm run android:assemble
  • npm run desktop
